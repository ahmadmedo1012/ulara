## What the captures found (the reason this item was not a formality)
At font_scale=2.0 the welcome screen was BROKEN: the display headline's line
box stayed at its absolute pixel lineHeight while fontSize doubled, so the
glyphs collided and climbed into the illustration, and the secondary line ran
off the container edge.

Root cause, app-wide (not screen-specific): `components/ui/text.tsx` set a
fixed pixel `lineHeight` per type variant. React Native scales `fontSize` with
the OS text setting and does NOT scale `lineHeight`.

Fix: `scaleLineHeight()` makes the line box follow the same font scale and
never drop below the house Arabic floor 1.35 x fontSize at that scale; at
fontScale 1 it returns the variant UNCHANGED (the designed type scale is
untouched at normal size). The welcome title's hardcoded `lineHeight: 40`
(ratio 0.91) is gone and its stack may wrap (flexShrink).

Before/after images: `device-200pct-before.webp` (this run) and
`device-200pct-after.webp` (the re-captured build).
