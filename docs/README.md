# مركز توثيق أُلارا

> الغرض: فهرس التوثيق الحي لمنصّة أُلارا (تعليم ذكي، عربية-أولًا، مستقلّة).
> القاعدة الذهبية: الشيفرة مصدر الحقيقة؛ إن خالفت وثيقةٌ السلوكَ الفعلي فالشيفرة تفوز ويُصحَّح النص.
> كل ملف هنا يبدأ بغرضه في ثلاثة أسطر ثم المحتوى.
> بيانات العرض كلها تخصّ «مساحة عمل أُلارا التجريبية» — اصطناعية وموسومة بوضوح، لا تحاكي أي مؤسسة حقيقية.

## مسارات قراءة مقترحة

- **أفهم المشروع:** `README.md` في الجذر ← `architecture.md` ← `deployment.md`.
- **سأطوّر ميزة:** `AGENTS.md` (الجذر) ← `architecture.md` (وحدة قطاعك) ←
  `DESIGN.md` (النظام البصري) ← `scripts/README.md` (بوابات ما قبل الدفع).
- **أدير أو أنشر:** `deployment.md` ← `runbook.md` ← `ops/LEDGER.md`.
- **أعمل على الجوال:** `mobile.md` ← `testing.md` (قسم android-smoke).
