## 1. ملخص المشروع والبنية الحالية

**أُلارا (Ulara)** — «نظام تشغيل الجامعة»: منصّة أكاديمية متكاملة مستقلّة، عربية-أولًا (RTL)،
خمسة أدوار (طالب/أستاذ/مسجل/جودة/مالك) + زائر. تقنيًا:

| الطبقة | التقنية | ملاحظات مقاسة |
|---|---|---|

| الواجهة | React 18 + Vite SPA | بناء ناجح؛ بوابة الحجم PASS (862.9 KB gz إجمالي / 30.0 دخول / 95.7 pdf) |

| الجودة | 11 مهمة في `ci.yml` + 8 مسارات CI أخرى + `scripts/verify.sh` محليًا | `grep -cE "^  [a-zA-Z0-9_-]+:$" ci.yml` = 11 |

## 6. الأمان

**التقييم الإجمالي: منخفض (LOW).**

- **لا أسرار إنتاجية** في الشجرة المتتبعة ولا في كامل التاريخ (مسح أنماط: `sk-`، `ghp_/github_pat_`، `AKIA`، `xox*-`، `AIza`، `hf_`، `BEGIN PRIVATE KEY`، سلاسل `postgres://user:pass` حقيقية — صفر إصابات؛ pickaxe على `git log --all` للامتدادات الحساسة: لا شيء سوى `.env.example`).
- `.env.example` = عناصر بديلة فقط (3 إلزامية + 30 اختيارية موثّقة)؛ `.gitignore` يمنع `.env*` و`backups/` وقواعد SQLite؛ شجرة العمل نظيفة تمامًا (`git status --porcelain --ignored` فارغ).
- `backend/src/env.ts`: تحقق zod صارم — `DATABASE_URL` + سِرّا JWT ‏≥32 بايت مختلفان إلزاميان، فشل-مغلق لأي تكوين نصفي (S3/AI/بريد)، لا wildcards في CORS، بذرة بديلة فقط تحت `NODE_ENV=test`.
- CI: كل بيانات الاعتماد عبر `secrets.*`، أسرار JWT تولَّد وقت التشغيل (`openssl rand -hex 48`)، بيانات PostgreSQL في المهام كلها محلية خطرة (`postgres:postgres@localhost`) أو dummy موسوم «disposable».
- حسابات الاختبار معلنة بحكم التصميم (`*@test.ly` / `12345678`، المصدر الموحّد `shared/testAccounts.ts`) — بيئة تطوير، وكلمة المرور محجوبة عن التسجيل، وتفعيل ضمانها عند الإقلاع يتطلب `ULARA_TEST_ACCOUNTS=1`.
- البذور التجريبية (`@demo.ulara.ly`) تسجيل يدوي فقط — توصية تحصين مذكورة في TD-09.
- الوجدتان الحيدتان (L-1 توكن CWV الطرف الثالث، وثيقة تاريخية في السجل الهندسي عن ثغرة أصلَت وتُرقّعت سابقًا) مؤجَّلتان بمسارات واضحة — لا يُنشر أي سر في هذا الـPR.
