# البنية المستهدفة المقترحة — TARGET_STRUCTURE

> الغرض في ثلاثة أسطر: خطة بنية مجلدات مستهدفة **اقتراحًا فقط** — لا حركة ملفات واحدة نُفِّذت
> في هذا الـPR، لأن أي نقل يلامس الاستيرادات أو السكربتات أو سجلات الجولات المجمّدة يجب أن
> يمر كـPR مستقل بتنفيذ متدرّج وتحقق بوابات كامل (`bash scripts/verify.sh`).
> الأساس: البنية الحالية سليمة التنظيم؛ ما يلي ترقية متدرجة لا إعادة بناء.

## المبدأ الحاكم

قواعد `AGENTS.md` غير قابلة للتفاوض هنا: لا إعادة تسمية تجميلية لمسارات/حقول/نماذج (أسماء
عقد)، لا كسر لبوابات zero-trace والحجم والكود الميت، و«الشيفرة تفوز». لذلك كل بند أدناه
يحمل: الخطوات، المخاطر، شرط الأمان، وخطة الرجوع.

## البنود المقترحة (بترتيب الأمان تنازليًا)

### S-1: أرشفة مسابر الجولات إلى سجلاتها — أمان مرتفع

- **النقل:** `scripts/audit/{r355,r358}/*` + `r360-landing-height.mjs` + `r362-shot.ts` +
  `r362-overlap.ts` → `docs/redesign/<الجولة>/instruments/` (أدوات «سجل الجولات» تسكن مع
  السجل الذي يستشهد بها).
- **الخطوات:** نقل الملف → تحديث كل الاستشهادات النصية في `LEDGER.md`/`REPORT.ar.md`
  (grep `scripts/audit/` في docs) → تشغيل `verify.sh --fast` + `deadcode/check.sh`.
- **المخاطر:** سجلات الجولات مجمّدة («إضافة فقط» بالروح) — تعديل الاستشهادات داخلها يحتاج
  قرار مالك؛ البديل الأدنى: إبقاء الملفات ووضع `scripts/audit/README.md` يشرح أن المحتوى
  أدوات أدلة مجمّدة لا جزء من بوابة `verify.sh` (سطر واحد، صفر مخاطرة).
- **شرط الأمان:** لا ينفَّذ إلا مع موافقة المالك على لمس نصوص السجلات.

### S-2: خفض أسماء الجولات من شجرة الإنتاج — أمان متوسط

- **النقل (بعد حسم TD-02 فقط):** `frontend/src/components/illustrations/r359/` →
  `.../illustrations/grammar/` مع تحديث `PlatesPage.tsx` (المستورد الوحيد)، ومسار مخرجات
  `scripts/art/gen-wrappers.mjs`، وglob في `scripts/art/check-art-colors.sh`، وقسم §5.7 في
  `ART-GRAMMAR.md`.
- **لماذا مؤجل:** يتشابك مع قرار «حذف الأغلفة الـ44 أم توصيلها» — قرار عقد مالك، لا تنظيف.
- **الرجوع:** `git revert` — النقل آلي بمسار واحد للمستوردين.

### S-3: سياسة احتفاظ لأدلة `docs/redesign/` — ضرورة وليست رفاهية (يرتبط TD-01)

- **المقاس:** docs عند 59,126/59,392 KB — متاح 266 KB. أي جولة أدلة قادمة ستحمر CI.
- **الخياران (قرار مالك):**
  - **أ)** أرشفة الأدلة خارج الشجرة: أصول GitHub Release لكل جولة + ملف `INDEX.md` بالروابط
    والخلاصات داخل الشجرة (يحرر ≈29 MB من r358 وحده).
  - **ب)** سقف لكل جولة + «أفضل قصاصات» فقط داخل الشجرة (retention policy مكتوبة في
    `size-gate.sh` الرأس، رفع لا خفض للسقف العام ممنوع دون سجل).
- **الرجوع:** الأصول المأرشفة لا تفقد — الشجرة أخف فقط.

### S-4: توحيد بوابة المعمارية — أمان مرتفع (تم جزئيًا في هذا الـPR)

- الوضع بعد هذا الـPR: `docs/architecture.md` = الوثيقة الحيّة العربية (تبقى المصدر)،
  `docs/architecture/` = مخططات C4 كصورة لحظية تزامن معها، `README.md` الجذر يشير إليهما.
  لا `ARCHITECTURE.md` ثالث في الجذر **عمدًا** — ثلاث نسخ معمارية = انجراف مضمون.
- **المتبقي المقترح:** سطر تمييز في رأس `docs/engineering/ARCHITECTURE.md` يوسمه «مراجعة
  هندسية تاريخية (نوفمبر 2026) — الحيّ في `docs/architecture.md`» (تعديل سطر، مقترح للـPR
  القادم).

### S-5: فهرس كامل لـ`scripts/` — أمان مرتفع

- `scripts/README.md` فهرس بوابات فقط؛ العشرات الأخرى (art/, brand/, e2e/, sql/, load/,
  media/, db-ops) بلا فهرس → TD-07: جدول بكل سكربت + مستدعيه (npm/CI/يدوي) + حالة
  (حية/أداة أدلة مجمّدة).

### S-6: ما **لا** يُنقل ولا يُسمّى (قرارات سلبية موثّقة)

- `backend/src/http/routes/*`، مسارات expo-router، حقول Prisma، متغيرات البيئة — عقد.
- `shared/art/` ↔ نسخة الجوال المولّدة — تكرار مُدار بأداة معلنة (ADR-0003).
- `tools/`، `.agents/`، `api/index.ts`، ملفات `.size-gate-allowlist`/`.vercelignore` —
  بنية تحتية حية موثّقة.
- سجلات الجولات المجمّدة نفسها (`docs/redesign/r3xx/*`) — مصداقية الإثبات.
